## About

This module introduces students to Bootstrap, its foundational concepts, and its responsive design capabilities. Participants will learn to utilize Bootstrap’s 12-column grid system for layouts, integrate JavaScript-dependent components like mobile navbars, and customize the default CSS to create unique, visually appealing web designs.

## Prerequisites

- Intro to CSS
- Intermediate CSS
